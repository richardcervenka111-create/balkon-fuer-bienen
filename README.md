# Balkon für Bienen

20 Pflanzen, die auf einem Berner Balkon Wildbienen, Hummeln und Schmetterlinge ernähren: Monat wählen, sehen, was jetzt blüht und was jetzt gesät oder gepflanzt wird. Sieben Regeln, die mehr bringen als jedes Insektenhotel aus dem Baumarkt. DE/EN, kein Tracking.

Live: **https://richardcervenka111-create.github.io/balkon-fuer-bienen/**

## Warum

Die Stadt Bern pflegt 23 000 Bäume, aber die Balkone gehören den Bewohnerinnen. Zehntausende Balkonkästen mit ungefüllten, gestaffelt blühenden Pflanzen sind ein Nahrungsnetz, das keine Behörde bauen kann. Die Information dazu ist verstreut; hier ist sie auf einer Seite, nach Monat.

## Grundlage

Pflanzenauswahl und Blühzeiten nach Empfehlungen von Bioterra und Pro Natura für das Schweizer Mittelland, angepasst an die Balkonpraxis in Bern (ca. 550 m). Blühmonate sind Richtwerte.

## Ehrlich gesagt

Keine botanische Datenbank, sondern eine kuratierte Liste. Wer eine Pflanze mit besserer Quelle ergänzen oder korrigieren will: Issue oder Pull Request mit Quelle.
